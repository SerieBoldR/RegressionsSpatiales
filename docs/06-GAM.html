5  Modèles généralisées additifs

Les Modèles Généralisés Additifs (GAM) sont une famille de modèle très flexibles permettant notamment de modéliser des relations non paramètriques entre les variables indépendantes et la variable dépendante d’un modèle.

En effet, dans un modèle de régression classique, nous partons du principe que les variables X (indépendantes) ont un impact linéaire sur la variable Y (dépendante). Cette hypothèse simplifie grandement les relations entre les variables observées et permet d’interprêter les résultats plus facilement (analyse des coefficients). Cependant, cette hypothèse peut être fausse et les relations non linéaires ont plus tendance à être la norme que l’exception.

Dans un GAM, plutôt que modéliser une relation linéaire, nous partons du principe que la relation modélisée peut être non-linéaire et suivre une fonction f. On parle donc de relations non-paramétrique car la forme de cette fonction s’ajuste au données et ne suit pas une forme pré-déterminée.

Ces fonctions f sont le plus souvent estimée avec des splines. Le fonctionnement de base est assez simple. Pour chaque variable X devant suivre une relation non-linéaire, la variable est remplacée par k sous-variable (x1, x2, …, xk). k représente le niveau de complexité attendu de la relation, plus k est grande, plus la fonction à ajuster pourra être complexe. Le modèle va estimer un coefficient pour chacune de ces sous-variable, et la somme des effets de ces sous-variables permet de reconstruire la relation non-linéaire.

La figure (figure 5.1) permet d’illustrer ce principe. Les lignes grises représentent les sous-variables, aussi appelées bases, qui sont ensuite multiplées par leur coefficient respectif pour obtenir leurs effets (en couleur), puis la ligne bleue représente leur somme. La ligne bleue capture très efficacement la relation entre la variable X et Y.

5.1 Comment utiliser une spline pour ajouter l’espace dans un modèle

Nous venons de voir qu’une spline permet de représenter l’impact potentiellement non-linéaire d’une variable indépendante sur une variable dépendante. Il est possible d’utiliser des splines pour intégrer un effet spatial dans un modèle. Pour cela, il faut considérer un type de spline un peu spécial : les splines bivariées.

Une spline bivariée permet de capturer l’effet simultanée de deux variables indépendantes sur une variable dépendante. Dans un contexte spatial, celle permet par exemple de capturer comment un changement dans les coordonnées X et Y impacte la variable dépendante. De plus, compte tenu de la forme des fonctions de base utilisées, les splines permettent généralement de capturer des relations spatiales avec une forte autocorrélation spatiale positive.

Prenons un exemple avec un jeu de données fictifs et admettons qu’il représente des mesures de pollutions effectuées à différentes localisation sur un territoire (figure 5.2).

Nous pourrions créer des bases d’une spline qui varient à la fois dans les coordonnées spatiales X et Y. L’animation à la figure (?fig-gam3) illustre des bases obtenues (k = 25) pour les données ci-dessus.

Si nous ajustons un coefficient pour chaque base et que nous combinons les effets de chaque base, nous obtenons un effet spatial permettant de prédire la variable de pollution. Nous le représentons ici à la figure (figure 5.3). Nous constatons ainsi que le modèle a été capable de reproduire les tendances principales des niveaux de pollution en retrouvant les secteurs avec des valeurs fortes et faibles. Plus l’autocorrélation spatiale est élevée, plus ce type de modèle est efficace pour capturer l’effet spatial.

d’un point de vue plus formel, un modèle GAM peut être décrit par l’équation suivante:

\[ \begin{aligned} &y \sim D(\mu,\theta)\\ &g(\mu) = \beta_0 + \beta X + \sum^{n}_{j=1}(f_j(\zeta_j))\\ \end{aligned} \tag{5.1}\]

avec :

  • \(y\), la variable dépendante.
  • \(D\), une distribution avec une espérance \(\mu\) et ses autres paramètres \(\theta\)
  • \(X\), les variables indépendantes dont l’effet est supposé linéaire par le modèle
  • \(\beta\), les coefficients des variables indépendantes.
  • \(\beta_0\), l’intercept
  • \(\zeta\), les variables dont l’effet est supposé non-linéaire par le modèle
  • \(f_j\), une fonction modélisant l’impact de la variable \(\zeta_j\)

Pour un modèle incluant seulement une spline bivariée sur les coordonnées de ses observations, le modèle peut se résumer à l’équation suivante.

\[ \begin{aligned} &y \sim D(\mu,\theta)\\ &g(\mu) = \beta_0 + \beta X + f(sp)\\ \end{aligned} \tag{5.2}\]

avec \(sp\) une matrice de deux colonnes comprenant les coordonnées cartésiennes des observations.

5.2 Pourquoi recourir à un modèle GAM?

Les modèles GAM son très flexibles puisqu’ils sont une extension directe des modèles GLM. Ils peuvent donc être appliqués à des variables dépendantes suivant des distributions très variées (normal, gamma, binomiale, poisson, tweedie, log-normal, etc.). Cependant, ils imposent une conceptualisation particulière de l’espace. En effet, un modèle GAM n’inclue pas directement la notion de dépendance spatiale dans sa formulation. L’hypothèse d’indépendance des observations est conservée (contrairement à un GLS). Le modèle intégre simplement un terme flexible correspondant à l’ajout d’un ensemble de nouvelles variables X structurées de tel sorte à capturer un effet spatialement positivement autocorrélé.

Si nous reprenons notre exemple avec la pollution atmosphérique, le modèle est un simple GLM supposant que les niveau de pollution suivent une distribution normale dont les observations sont indépendantes. Cependant la moyenne de cette distribution peut être prédite avec une spline calculée à partir des coordonnées spatiales des observations. Le modèle ne part donc pas du principe que deux observations proches sont plus similaires, mais seulement qu’il existe un effet spatial permettant de prédire les niveaux moyens de pollution attendus. Un modèle GAM ne vise donc pas explicitement à corriger l’effet de la dépendance spatiale, mais plutôt à capturer un effet spatialement structuré et non capturé par les variables indépendantes X. Sans l’ajout de la spline, cet effet ce serait retrouvé dans les résidus du modèle.

La cartographie de l’effet spatial dans un modèle GAM permet de visualiser les secteurs dans lesquels, toute chose étant égales par ailleurs, la variable dépendante est plus forte ou plus faible que la moyenne régionale. Il peut être vu comme un ajustement local de la prédiction. Une forme de malus ou de bonus que le modèle ajoute à sa prédiction pour tenir compte de la variation spatiale de la variable dépendante qui n’a pas été expliquée par les variables indépendantes.

Cependant, puisqu’un modèle GAM ne prends pas directement en compte l’autocorrélation spatiale, il est tout à fait possible qu’il échoue à réduire suffisamment la dépendance spatiale des résidus d’un modèle. Il faudra alors privilégier d’autres formes de modèles. De même, si notre cadre théorique nous amène à penser que nos observations s’influencent mutuellement dans l’espace, il sera beaucoup plus cohérent d’utiliser un modèle économétrique.

Prenons un exemple concret pour lequel utiliser un modèle GAM serait particulièrement adapté. Dans l’article de Gelb et Apparicio (2022), les auteurs cherchent à modéliser les niveaux d’expositions de cyclistes aux pollutions atmosphériques et sonores. Les données utilisées ont été collectées par des cyclistes qui parcouraient différents environnements urbains équipés de capteurs de bruit et de pollution. L’objectif de l’étude était de déterminés quels caractéristiques de l’environnement urbain contribuaient à augmenter les niveaux d’exposition des cyclistes. Dans leur cadre théorique (figure 5.4), les auteurs distinguent deux types d’effets :

  1. les effets du micro-environnement, causés par les caractéristiques locale comme le type de rue utilisé, la densité bâtie, la présence de végétation, etc.
  2. la pollution d’arrière plan, causée par des phénomènes géographiques régionaux comme la localisation des industries, des autoroutes, la topographie, etc.

L’exposition mesurée pour un cycliste à un endroit t dépend donc des caractéristiques propres de cet endroit, mais aussi de la pollution d’arrière plan. Par exemple si nous prenons une rue A, en tout point identique à une rue B, nous pouvons nous attendre à mesurer des niveaux de pollution plus élevée pour B si celle-ci se trouve dans un secteur plus industriel de la ville. Cette différence ne s’explique pas par des caractéristiques propres à A ou B (pusiqu’elles sont identiques), mais bien par un effet d’arrière plan, produit par différents phènomènes géographiques et donc spatialement autocorrélés.

Dans cet exemple, intégrer la pollution d’arrière plan avec une spline spatiale est particulièrement pertinent car l’interprétation de l’effet produit par cette spline s’intègre directement dans le cadre théorique.

5.3 MRF ou spline bivariée?

Nous avons vu jusqu’ici qu’il est possible d’ajouter un effet spatial dans un modèle GAM en intégrant une spline bivariée sur les coordonnées spatiales des observations. Cette approche est cependant moins pertinente quand les observations sont des polygones de tailles variés. En effet, intégrer les centroids des polygones dans le modèle revient à nettement déformer l’espace de nos données puisque des polygones voisins peuvent avoir des centroids très éloignés.

Lorsque les données ont une géométrie de type linéaire ou polygonale, il est recommandé d’utiliser un autre type de spline appelée un champ de Markov aléatoire (random Markov field - RMF an anglais).

Mathématiquement parlant, un modèle de type CAR (conditionnal autoregressive model) est très proche d’un modèle GAM intégrant un RMF puisque la structure spatiale intégrée par un modèle CAR est un RMF : La valeur de la variable dépendante d’une entité est conditionnée par la valeur de ses voisins. Dans l’équation équation 5.3, le terme \(\eta\) représente l’effet spatial. Il est le plus souvent modélisé comme un effet provenant d’une distribution normale multivariée, centrée sur zéro et dont la matrice de covariance est calculée grâce à un terme \(\lambda\) et une matrice de pondération spatiale \(W\). Ce type de modèle est communément appelée un modèle à effet mixte car il combine des effets fixes (les coefficients \(\beta\)) et des effets aléatoires (\(\lambda\)). Les effets aléatoires ne sont pas estimés de la même façon que des effets fixes, ils sont en effet pénalisés. Pour une introduction sur les modèles à effets mixtes, vous pouvez consulter ce chapitre sur les GLMM du livre Méthodes quantitatives en sciences sociales : un grand bol d’R (Apparicio et Gelb 2022).

\[ \begin{aligned} &y \sim D(\mu,\theta)\\ &g(\mu) = \beta_0 + \beta X + \eta \\ &\eta \sim Normal(0,(I - \lambda W)\sigma^2) \end{aligned} \tag{5.3}\]

Il existe un lien direct entre les GLMM et les GAM. En effet, il est possible de reformuler un GLMM comme un GAM et vice-versa ce qui signifie qu’une spline pénalisée peut être utilisée pour représenter un effet aléatoire (Wood 2017).

Dans R, avec le package mgcv, il est possible d’utiliser une spline pénalisée par une matrice de pondération spatiale pour approximer l’effet aléatoire que nous aurions modélisé avec un modèle de type CAR. L’intéret d’utiliser un GAM plutôt qu’un CAR est que nous pouvons contrôler directement le degré de lissage (autocorrélation spatiale) du terme spatial dans le modèle grâce au nombre de degrés de libertés (k) de la spline. En utilisant un nombre de degré de liberté maximal (\(k = n-1\)), soit une base par observation, alors on obtient un full rank MRF, autorisant de facto la plus grande variance possible du terme spatial. En réduisant k, nous obtenons des modèles d’ordre inférieur (low-rank MRF) dont le terme spatial est plus lisse et moins complexe.

\[ \begin{aligned} &y_i \sim D(\mu_i,\theta)\\ &g(\mu_i) = \beta_0 + \beta X_i + f(W_i) \\ \end{aligned} \tag{5.4}\]

5.4.1 Réalisation du modèle GAM

Pour illustrer la réalisation d’un modèle GAM dans R, nous allons nous intéresser aux parts modales dans la région métropolitaine de Montréal. Il s’agit d’un ensemble de trois variables mesurant respectivement la proportion des indivdidus utilisant la voiture, le transport collectif ou un mode actif comme mode de transport principal pour ses déplacements pendulaires en 2021 au niveau des secteurs de recensement.

Lorsqu’un ensemble de variables sont des proportions d’un total (leur somme donne 1 ou 100), alors on désigne l’ensemble de ces variables comme des données compositionnelles. Ces données doivent être analysées avec des méthodes spécifiques car elles ont un comportement particulier. La diminution de l’une d’entre elle provoque nécessairement l’augmentation d’une autre. Elles ne sont donc pas indépendantes et certaines catégories ont même tendance à exister simultanément ou au contraire se repousser.

L’analyse de données compositionelles est un domaine en soit et sort du matériel que nous souhaitons couvrir dans ce livre. Il existe d’excellentes ressources et packages R pour les personnes intéressée Tsagris et Athineou (2025).

Nous allons ici utiliser l’approche du log des ratios (alr). Il s’agit d’une transformation que l’on peut appliquer aux données compositionnelles pour pouvoir les analysers avec des méthodes classiques de statistiques. On lui préfère généralement une autre méthode de tranformation, soit la transformation isométrique des log ratios (ilr), mais cette dernière produit des résultats plus difficiles à interprêter (Greenacre, Martı́nez-Álvaro et Blasco 2021). Nous utiliserons donc l’approche alr dans cet exemple.

La transformation alr est décrite par la formule suivante:

\[ \begin{equation} \operatorname{alr}(x)=\left[\log \frac{x_1}{x_D}, \cdots, \log \frac{x_{D-1}}{x_D}\right] \end{equation} \]#eq-ALR

Pour une variable compositionnelle x comprenant D dimensions (catégories), la transformation alr consiste à calculer D-1 log de ratio entre les différentes dimmensions D et une référence parmi D. Donc le nombre de dimensions de la version transformée de x est toujours de D-1.

Pour notre exemple, nous allons nous concentrer sur le ratio entre utilisateurs du transport collectif (TC) et de l’automobile.

Puisque la transformation alr implique une division, puis un log, il est important que ni le numérateur ni le dénominateur ne soit 0. Dans notre cas, nous avons quelques SR avec des parts modales TC à 0. Il semble peu probable que strictement personne dans un SR n’utilise le transport collectif, nous allons donc remplacer ces 0 par le plus petit pourcentage trouvés dans les SR dont la valeur est supérieure à 0.

Pour valider les résidus de ce modèle, nous utiliserons la méthode des résidus simulés. Vous trouverez plus d’information à leur sujet dans le chapitre sur les GLM du livre Méthodes quantitatives en sciences sociales : un grand bol d’R (Apparicio et Gelb 2022).

library(mgcViz)

glm_base <- gam(alr_val ~ prt_minorite_vis + prt_monoparental + revenu_median +

plot(res)

La figure figure 5.7 ci-dessus indique que nos résidus simulés ne suivent pas vraiement une distribution uniforme et sont marqués par des valeurs extrèmes. Pour améliorer notre modèle, nous allons le réajuster mais ne utilisant une distribution de Student. Cette dernière ressemble beaucoup à la distribution normale, mais admet davantage de valeurs extrèmes. Elle permet donc de réduire l’impact des valeurs extrèmes dans le modèle.

glm_base <- gam(alr_val ~ prt_minorite_vis + prt_monoparental + revenu_median +
                  acs_idx_emp_tc_peak + acs_idx_emp_pieton,
         data = data_mtl, family = scat)

# validation brève des résidus
res <- simulateResiduals(glm_base, plot = F)

plot(res)

Nous notons une nette amélioration à la figure figure 5.8, bien que les quantiles des résidus tendent encore à dévier des valeurs attendues. Ceci peut s’expliquer de plusieurs façon, mais ici, il est tout à fait possible que le phénomène soit provoqué par de l’autocorrélation spatiale dans les résidus.

Chacune de nos variables explicative a un impact significatif sur le ration entre part modale TC et part modale auto. Pour interprêter leurs effets, nous devons tenir compte de l’impact de la transformation alr. Pour rappel, notre modèle prédit la moyenne de notre log du ratio entre la part TC et la part automobile. Il est possible de passer de l’échelle log à l’échelle naturelle en utilisant la fonction exponentielle (exp). Si nous transformons les coefficients obtenus avec la fonction exp, alors ils expriment l’impact multiplicatif des variables indépendantes sur le ratio entre la part TC et la part automobile. Si ce ratio augmente, c’est que l’automobile est moins utilisée et/ou que le TC est plus utilisé et inversement.

Voici une interprétation des effets obtenus:

  • Comparativement à un SR avec 0% de personnes issues des minorités visible, un SR avec 25% de ce groupe de la population verrait augmenter la moyenne du log du ratio de 0.876 * 0.25 = 0.219, ce qui correspond à une multiplication par 1.245 du ratio, ou encore, une augmentation de 24.5% du ratio. Il semblerait donc que toutes choses étant égales par ailleurs, la concentration des minorités visibles soit associée avec une plus grande proportion d’utilisation du TC et/ou une plus faible utilisation de la voiture.

  • Comparativement à un SR avec 0% de ménages monoparentaux, un SR avec 25% de ce groupe de la population verrait augmenter la moyenne du log du ratio de 1.398 * 0.25 = 0.3495, ce qui correspond à une multiplication par 1.418 du ratio, ou encore, une augmentation de 41.8% du ratio. Il semblerait donc que toutes choses étant égales par ailleurs, la concentration des ménages monoparentaux soit associée avec une plus grande proportion d’utilisation du TC et/ou une plus faible utilisation de la voiture.

  • Lorsque le revenu médian dans un SR augmente de 1000 dollars, on observe une réduction de la moyenne du log du ratio de -0.01, soit une multiplication du ratio par 0.99. En d’autres termes, le ratio diminue de 1% à chaque millier de dollars supplémentaire. Il semblerait donc que dans les SR les plus nantis, l’utilisation du TC soit plus délaissée au profit de la voiture.

  • Lorsque que l’accessibilité aux emplois en transport collectif est plus élevée, la moyenne du log du ratio augmente. Dans un SR avec le pire niveau d’accessibilité possible, augmenter l’accessibilité au niveau du premier quartile (au moins mieux que 25% des SR) serait associé avec une augmentation de la moyenne du log du ratio de 3.936 * 0.25 = 0.984 , ce qui correspond à une multiplication par 2.675 du ratio.

  • Cependant, lorsque l’accessibilité à pied augmente, nous pouvons observer une réduction de la moyene du log du ratio. Dans un SR avec le pire niveau d’accessibilité possible, augmenter l’accessibilité au niveau du premier quartile (au moins mieux que 25% des SR) serait associé avec une augmentation de la moyenne du log du ratio de -1.549 * 0.25 = -0.38725 , ce qui correspond à une multiplication par 0.679 du ratio, ou encore une réduction de 32.1%. Ce résultat s’explique vraisemblablement par l’utilisation des modes de transport actifs plutôt qu’une utilisation accrue de la voiture.

Dans le résumé du modèle, nous pouvons observer que la spline utilisée pour capturer l’effet spatial à un effet significativement différent de 0 et comporte environ 27 degrés de libertés. Pour pouvoir observer l’effet de cette spline, nous devons utiliser l’approche des effets marginaux. Cette approche consiste à effectuer une prédiction avec le modèle de la valeur attendue de la variable Y en conservant identiques toutes les variables indépendantes, sauf la localisation dans l’espace. En d’autres termes, nous essayons de voir comment le modèle s’ajuste quand on lui demande de prédire la valeur Y pour une observation spécifique, mais que celle-ci est déplacée dans l’espace. Ainsi, la variation de la prédiction est affectée uniquement par l’espace.

Pour obtenir l’effet uniquement spatial, nous pouvons mettre arbitrairement toutes les valeurs à 0 des différentes variables indépendantes du modèle. Ainsi, même multipliées par leurs coefficients, leur contribution dans la prédiction restera 0. Il suffit ensuite de retirer l’intercept pour ne bien garder que l’effet de la spline.

5.4.1.2 GAM avec spline spatiale de type RMF

Puisque nos observations sont des polygones, utiliser leur centroid pour représenter l’espace est une approximation maladroite. Nous allons donc opter pour un markov random field.

L’enjeu avec ce type de modèle est de sélectionner son rang. Pour cela, nous allons tester plusieurs valeurs allant de 10 à 250 autorisant une complexité grandissante du terme spatial. Notons d’emblée que notre spline bivariée précédente avait nécessité seulement 25 degrés de libertés supplémentaires. La sélection de k (le nombre de degré de liberté accordé au MRF) reposera sur deux critères: l’autocorrélation spatiale encore présente dans les résidus (I de moran calculé sur les résidus de Pearson) et le AIC (pénalisant la complexité des modèles).

Pour accélérer le calcul, nous allons ici effectuer cette opération en mode multiprocessing. 4 coeurs indépendants s’occuperont d’ajuster les différents modèles.

library(future)
library(future.apply)

# nous préparons les informations de voisinage pour le terme MRF
nb <- poly2nb(data_mtl)
names(nb) <- as.integer(attr(nb, "region.id"))
data_mtl$ID_LOC <- as.integer(attr(nb, "region.id"))

ks <- seq(10,250,20)

# nous allons itérer sur les valeurs de ks et ajuster nos modèles
# nous récupérons à chaque fois les informations pertinentes dans nos 
# résidus

S0 <- sum(sapply(queen_w$weights, sum))

future::plan(future::multisession(workers = 4))

resultats <- future_sapply(ks, function(k){
  
  model <- gam(alr_val ~ prt_minorite_vis + prt_monoparental + revenu_median +
                  acs_idx_emp_tc_peak + acs_idx_emp_pieton + 
              s(ID_LOC, bs = 'mrf', xt = list(nb = nb), k = k),
         data = data_mtl, family = scat)
  
  resid <- residuals.gam(model, type = 'scaled.pearson')
  I <- moran(resid, queen_w, n = length(resid), S0 = S0, zero.policy = TRUE)
  aic_score <- AIC(model)
  return(c(I[[1]],aic_score,k))
})

df_plot <- data.frame(t(resultats))
names(df_plot) <- c('moranI', 'aic', 'k')
plot1 <- ggplot(df_plot) + 
  geom_line(aes(x = k, y = moranI), color = 'black') +
  geom_point(aes(x = k, y = moranI), color = 'red') + 
  labs(x = 'k', y = 'I de Moran') + 
  theme_bw()

plot2 <- ggplot(df_plot) + 
  geom_line(aes(x = k, y = aic), color = 'black') + 
  geom_point(aes(x = k, y = aic), color = 'red') + 
  labs(x = 'k', y = 'AIC')+ 
  theme_bw()

ggarrange(plot1, plot2)

La figure figure 5.11 permet de constater que le AIC et le I de Moran diminuent à mesure que k augmente. Pour le I de Moran, nous constatons qu’au delà de k = 100, nous passons à des valeurs inférieures à 0,05. Aussi le AIC semble se stabiliser lorsque k > 150. Nous pourrions donc ajuter un modèle avec k = 150 pour avoir un bon compromis entre AIC et réduction du I de Moran des résidus.
